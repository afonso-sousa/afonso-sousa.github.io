# afonso-sousa.github.io

GitHub Pages site serving `app-ads.txt` for my published mobile apps.

`app-ads.txt` is the IAB authorized-sellers file AdMob checks against the developer website listed on a mobile app's store page. It declares which ad networks are allowed to sell inventory for those apps.

There is no site content here beyond that file — see [afonsousa.com](https://afonsousa.com) for the actual portfolio.
